# Contributing

Thanks for your interest in Chequer Image Studio.

## Reporting bugs and ideas

Open an issue and pick a template. For bugs, the platform, the version and the steps to reproduce help the most. A screenshot or the file that triggers the problem helps even more.

## Sending code

1. Fork the repository and create a branch.
2. Build and run: `cargo run --profile fastrel -p chequer-app`.
3. Before opening a pull request, run `cargo fmt` and `cargo test`.
